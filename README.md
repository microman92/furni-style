# Furni Style

Сайт мебельной фабрики: Next.js 16, App Router, TypeScript, Tailwind CSS 4 и Motion. Создан в отдельной папке, чтобы не менять Daily Focus.

## Запуск

Требуется Node.js 22.13 или новее.

```powershell
cd 'D:\Миша\Работа PROWEB\Домашки\daily-focus\furni-style'
npm install
npm run dev
```

Сайт: http://127.0.0.1:3001.

```powershell
npm test
npm run typecheck
npm run build
npm start
```

Все страницы предварительно генерируются при сборке, включая 7 страниц услуг. POST `/api/lead` работает на сервере. Развёртывать как обычное приложение Next.js с Node.js, например через Vercel или собственный сервер. `output: 'export'` не используется: он не поддерживает серверный обработчик заявок.

## Данные и настройки

- `src/data/site.ts`: компания, контакты, регион, цифры, примеры отзывов и этапы.
- `src/data/services.ts`: 7 направлений, SEO-тексты, FAQ, фото и примеры портфолио.
- `src/data/pricing.ts`: базовые цены, размеры, материалы, коэффициенты, опции и услуги.
- `src/lib/calc.ts`: расчёт, округление до тысячи UZS и проверка импортируемых смет.
- `src/lib/calcStore.ts`: localStorage, синхронизация вкладок и импорт сметы через `#estimate=`.
- `src/app/globals.css`: токены, адаптивная сетка и стили. Шрифты загружаются через `next/font`.

Смета не содержит контактов. Ссылка передаёт только выбранные изделия и настройки. Параметры проверяются при восстановлении и повторно на сервере. До 20 изделий в смете. Для шкафа учитываются ширина × высота; для остальных изделий используются погонные метры комплекта. Сборка и срочность считаются от стоимости изделий и их опций; фиксированные услуги добавляются один раз.

## Перед публикацией

Все цены, показатели компании, изображения и отзывы демонстрационные. Заменить их реальными данными. В `site.ts` заменить `.example` на рабочий домен и реальные контакты. Политика конфиденциальности требует заполнения реквизитов и утверждения владельцем.

Форма проверяет имя, телефон +998, согласие и honeypot. Сейчас `/api/lead` пишет заявку в `console.info`, без постоянной базы и отправки менеджеру. Подключение Telegram/CRM делается здесь; проверять ответ интеграции перед показом пользователю подтверждения доставки.

Индексация намеренно закрыта в `layout.tsx` и `robots.ts`, пока не заменены демо-данные. После подготовки рабочего сайта включить индексацию в обоих местах. Telegram/WhatsApp и карта не ведут на вымышленные аккаунты: заполнить соответствующие реквизиты и добавить ссылки после проверки.

## Проверка

Аудит дизайна и ограничения автоматического проверяющего: [docs/taste-audit.md](docs/taste-audit.md).

`npm test` проверяет расчёт кухни и площади шкафа, несколько изделий, начисление услуг, опции, округление, отклонение некорректных смет и перенос через base64. В браузере проверены ширина 360px, мобильное меню, сохранение после перезагрузки, перенос квиза в полный калькулятор, фильтры портфолио и тестовая отправка формы. Метрики Lighthouse и Core Web Vitals не измерялись.
