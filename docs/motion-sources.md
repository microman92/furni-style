# Motion для Furni Style

Каталог: https://designbookmark.com/motion — просмотрен 12 ноября 2026.

| Материал                                                                    | Где используется                            | Адаптация                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Roll Links](https://designbookmark.com/motion#db-roll-links)               | Ссылки десктопной навигации, `RollLink.tsx` | Два экземпляра каждой буквы, вертикальное перекатывание с задержкой 18ms между буквами. Сохранены обычные ссылки и доступные названия. Вместо собственного RAF-движка применяется CSS. Автопроигрывание исключено; reduced-motion отключает переходы. |
| [Expand Card](https://designbookmark.com/motion#db-expand-card)             | Карточки изделий в `Calculator.tsx`         | По мотивам раскрытия карточек. AnimatePresence, анимация высоты, отдельные действия добавления и удаления. Реализация проекта, без копирования исходного компонента.                                                                                  |
| [Copy Button](https://designbookmark.com/motion#db-copy-button)             | Кнопка копирования ссылки на смету          | По мотивам обратной связи «скопировано». Clipboard API, временное подтверждение, сообщение об ошибке. Реализация проекта.                                                                                                                             |
| [Step Progress](https://designbookmark.com/motion#db-step-progress)         | Три шага QuickCalc                          | Размер, изделие и отделка; смена содержимого через AnimatePresence. Реализация проекта.                                                                                                                                                               |
| [Range Slider](https://designbookmark.com/motion#db-range-slider)           | Размеры мебели                              | Нативный доступный range с живым значением. Реализация проекта.                                                                                                                                                                                       |
| [Smooth Tab / Kokonut UI](https://kokonutui.com/docs/navigation/smooth-tab) | Подбор паттерна фильтров портфолио          | Источник вдохновения для состояния выбранного фильтра. Использованы простые кнопки `aria-pressed` и появление результатов через Motion. Исходный компонент не импортирован.                                                                           |

Визуальные токены и тексты оригинальных демо не перенесены. Палитра, Cormorant Garamond, Manrope, размеры и сетка соответствуют брифу Furni Style.

Для Motion используется [LazyMotion + domAnimation](https://motion.dev/docs/react-lazy-motion), компоненты `m`, `MotionConfig reducedMotion="user"`. Фотографии — запрошенные в брифе заглушки Unsplash; они не являются работами фабрики.
